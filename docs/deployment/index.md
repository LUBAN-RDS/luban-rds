## 部署方式

Luban-RDS 支持多种部署方式，适应不同的应用场景：

| 部署方式 | 适用场景 | 特点 |
|---------|---------|------|
| **独立服务** | 生产环境 | 独立进程，高性能，易管理 |
| **嵌入式** | 开发测试 | 零运维，快速集成 |
| **Docker 容器** | 容器化环境 | 标准化部署，易于扩展 |
| **Kubernetes** | 云原生环境 | 自动化运维，高可用 |
| **云服务** | 公有云环境 | 弹性伸缩，按需付费 |

## 环境要求

| 环境 | 最低要求 | 推荐配置 |
|------|----------|----------|
| **操作系统** | Windows 7+, Linux, macOS | Linux (CentOS 7+, Ubuntu 18.04+) |
| **Java 版本** | JDK 17+ | JDK 17+ (LTS) |
| **内存** | 512MB | 2GB+ |
| **CPU** | 1 核 | 2 核+ |
| **网络** | 100Mbps | 1Gbps |

## 关键特性

- **简单部署**：提供多种部署方式，适应不同场景
- **灵活配置**：丰富的配置选项，支持定制化部署
- **易于监控**：完善的监控指标和工具集成
- **高可靠性**：支持持久化、主从复制、集群模式
- **安全可控**：支持密码认证、命令限制等安全特性

## 部署流程图

```
环境准备 → 安装部署 → 配置优化 → 启动服务 → 验证服务 → 监控维护
```
